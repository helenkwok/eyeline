# Submission Verification Checklist & Protocol

---

## 1. Zero-Failure Principle: The Fresh-Clone Rehearsal

Judges frequently evaluate submissions from clean machines or virtual environments without reaching out to troubleshoot setup issues. Any setup friction—missing environment variables, unstated global dependencies, or absolute local paths—results in an immediate score of zero for technical implementation.

**The fresh-clone rehearsal must be performed as an empirical test, not a mental exercise:**

- [ ] **Clone into a Pristine Isolated Directory**: Run `git clone <repo-url> /tmp/eyeline-test` on a clean machine or isolated container.
- [ ] **Follow README Quickstart Verbatim**: Execute setup commands exactly as written without developer shortcuts or pre-existing local caches.
- [ ] **Verify Zero Hidden Environmental Dependencies**: Ensure no implicit reliance on local author paths, uncommitted files, or proprietary machine configurations.
- [ ] **Verify Graceful Degraded Mode**: If remote API credentials are not supplied, confirm the system falls back legibly to local fixture replay mode with clear user guidance (never an unhandled exception or blank screen).
- [ ] **Logged-Out Network Verification**: Confirm repository and hosted deployment URLs are fully accessible from an unauthenticated, logged-out browser outside the local network.

---

## 2. Hard Eligibility Gates (Failure = Immediate Disqualification)

- [ ] **Public Repository**: Repository is public and accessible without invitation or credentials.
- [ ] **Open Source License**: `LICENSE` (Apache-2.0) present at the repository root and detected by GitHub's license classifier.
- [ ] **Contest Window Compliance**: All git commits are timestamped within the official hackathon window (commencing 2026-07-27).
- [ ] **Originality**: Zero code ported or recycled from prior internal projects; development begins from first commit.
- [ ] **IBM Bob Provenance Evidenced**: Substantive subsystems authored via IBM Bob, transcripts archived under `.bob-transcripts/`, and prominently linked in `README.md`.
- [ ] **Google Cloud AI Exclusivity**: All AI interactions execute via official Google Cloud SDKs (`google-genai`, `google-cloud-aiplatform`) utilizing Gemini and Veo models. Zero third-party LLMs or unauthorized agent frameworks.
- [ ] **Devpost Form Partner Selection**: "IBM Track" explicitly selected on the Devpost submission portal.

---

## 3. Public Hosted Deployment

- [ ] **High-Availability Hosting**: Hosted instance deployed to a stable production endpoint (e.g., Google Cloud Run or Firebase App Hosting).
- [ ] **Frictionless Judge Access**: No mandatory account registration, paywall, or BYO-API-key requirement to view the working interface.
- [ ] **Persistent Post-Deadline Availability**: Instance remains active and responsive throughout the judging window.

---

## 4. Video Presentation (3-Minute Maximum, Public)

- [ ] **Strict Timing & Narrative Structure**:
  - `0:00 - 0:20`: The high-stakes set environment and the script supervisor's continuity problem.
  - `0:20 - 0:45`: The bottleneck of manual continuity logging across multiple camera setups.
  - `0:45 - 1:25`: Live demo: dual synchronized player, candidate region diffing, and localized Gemini continuity alerts.
  - `1:25 - 1:50`: The empirical benchmark: real-world metrics across positive defect pairs and negative control pairs.
  - `1:50 - 2:15`: The Veo pickup pipeline: synthesizing seamless ~2s bridging cutaways on Vertex AI.
  - `2:15 - 2:40`: **Dedicated Chapter: "Built with IBM Bob"** showcasing agentic development and transcripts.
  - `2:40 - 3:00`: Summary, architecture overview, and link to public hosted application.
- [ ] **Audio & Visual Quality**: Clean voiceover narration (tested for balanced gain, non-distorted audio) and sharp 1080p+ visual captures.
- [ ] **Hosting**: Public YouTube or Vimeo link with English voiceover and accurate subtitles.

---

## 5. Factual Integrity & Scientific Honesty

- [ ] **Synthetic Data Disclosure**: All synthetic media generated by Veo is explicitly flagged as synthetic in UI badges, code comments, and documentation.
- [ ] **Honest Benchmark Reporting**: Final headline metrics report actual script output directly from the automated scorer, including false passes and false alarms.
- [ ] **No Unverified Financial Claims**: Avoid quoting unsourced dollar statistics on reshoot losses; focus exclusively on verifiable operational time saved on set.
